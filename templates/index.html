Objective Function Formula

Objective Score =
  + 25.0 * (1 - ΔDifficulty / 2)
  + 25.0 * (1 - ΔUnit / 2)
  + 20.0 * (Covered Topics / Required)
  + 15.0 * (1 - |Marks - Target| / Target)
  + 15.0 * (Novelty & Type Diversity)

Normalized between 0 and 100. Displayed transparently on every generated paper and comparison result.
